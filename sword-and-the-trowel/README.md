# The Sword and the Trowel — section status

Spurgeon's monthly magazine (founded 1865), edited by Spurgeon until his death
on 31 January 1892; the Feb–Dec 1892 issues were seen through the press by his circle.

**Sourcing: complete for the Spurgeon era.** All 28 annual volumes, 1865–1892,
have been downloaded and verified (public-domain scans via Theology on the Web,
one searchable PDF per year; Internet Archive cross-checks for 1866, 1867, 1882
and 1889 — IA metadata dates are unreliable and its 1867 copy runs ~25% short,
so it is never used alone). Post-1892 volumes 1893–1904 exist at the same source
but were not downloaded; nothing openly downloadable was found beyond 1904.

**JSON build: in progress.** Planned format, mirroring the pulpit sections:
one JSON per annual volume (`sword-and-the-trowel-<YYYY>.json`), split to
individual articles with, per article: title, author as printed (many
contributors besides Spurgeon), month, department, start page, the same
cross-reference and proper-noun tagging as the pulpit set (see ../TAGGING.md),
and cleaned full text. Known processing caveats: OCR quality varies (donation
lists and £sd tables garble), and each source PDF carries one prepended
distributor notice sheet to strip.
